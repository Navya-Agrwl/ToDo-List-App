# TO-DO List App

A clean and responsive To-Do List web app built using HTML, CSS, and JavaScript.
It helps users manage daily tasks with features like task creation, completion tracking, reminders, filters, and local storage support.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Edit existing tasks
- Task priority selection
- Due date & time support
- Filter tasks (All / Completed / Pending)
- Data stored using Local Storage
- Responsive UI for mobile and desktop
- Simple and user-friendly design

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
